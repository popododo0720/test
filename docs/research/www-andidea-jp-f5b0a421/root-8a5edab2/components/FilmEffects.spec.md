Public API: useFilmEffects(rootRef: RefObject<HTMLElement|null>, videoRef: RefObject<HTMLVideoElement|null>): void; createDissolve(stage: HTMLElement) returns {render(elements: HTMLElement[], key: string, progress:number):void, invalidate():void, dispose():void}.
Use source-film-effects.js.txt in same artifact root as exact reference; original exported hooks u=ink adaptation, d=ASCII video pulse, f=pointer parallax and factory v=dissolve. Reimplement readable strictly typed TypeScript, no any/ts-ignore. Do not execute compiled original modules.
Ink: sample 9x5 points beneath each active heading against current displayed video frame, weighted brightness threshold .22 switch dark / .16 retain dark (hysteresis). Set data-film-ink="dark" or "light" on .journey-heading h1,h2. Original uses precalculated 48x27 brightness frames; local same-origin video permits canvas sampling instead. Test posterior coordinates cover/object-position.
Pointer: only fine hover pointers and no reduced motion, lerp .09; set stage variables --holo-rx=-y*2.6deg, --holo-ry=x*3.2deg, --holo-x=50+x*34%, --holo-y=50+y*34%, --holo-dx=-x*10px, --holo-dy=-y*8px, --float-x=x*25px, --float-y=y*19px, --shadow-x=-x*14px. Reset on pointerleave/visibility changes. Match source behavior and cleanup.
ASCII pulse: every 3000ms while playing/in viewport/visible; 580ms duration, throttle frames 45ms; sample downscaled video max 108 columns, draw cyan-to-purple gradient ASCII characters " .:+*X#@" over #041721e8. Source contains exact equations. Suspend when paused/seeking/reduced motion/hidden; clean timers and observers.
Dissolve: rasterize actual text using Range geometry and getComputedStyle (font/weight/style), sample alpha grid 7px desktop or 6px mobile, turn samples into @#X+=:. particles. Deterministic seed sin(x*12.9898+y*78.233)*43758.5453. Particle phase clamp((progress-(xNormalized*.18+seed*.14))/.68), opacity sin(pi*phase)^.55*clamp(progress*16), dx=(seed-.45)*300*phase², dy=-150*phase². Use original cyan/white trails, glyph sizing and particle phases. Hide when progress<=0 or >=1. Cache keyed section and viewport, invalidate on resize, remove on dispose.
Styles: source-derived .ascii-dissolve and .film-ascii-pulse rules are already in src/app/andidea.css; do not modify stylesheet.
Responsive: source uses <=700px small-particle branch, scales raster to max1200x900; pointer disabled coarse/touch.
Text content: canvas decorative; aria-hidden=true. No generated assets, no substitutes.
Validation: npx tsc --noEmit, cleanup correctness; do not modify other modules.
